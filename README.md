## 📌 Project Overview

QA project focused on manual testing of the **Urban Lunch** app — an Android application for ordering from restaurants with pickup at urban collection points.

---

## 🎯 Project Goals

Plan, execute, and document manual tests to identify functional issues in the first version of the **Urban Lunch** app.

---

## 🔧 Technologies and Tools

- 📝 **Google Sheets** — test checklist  
- 🐞 **Jira** — bug tracking and reporting  
- 📱 **Android Studio** — test execution  

---

## ▶️ How to Run

1. Install the **Urban Lunch** app on the **Pixel 5** emulator;  
2. Follow the test checklist in Google Sheets;  
3. Mark each test as ✅ Passed or ❌ Failed;  
4. Create bug reports in **Jira** for each issue found.  

---

## 🧾 Results

- Test checklist created and filled out;  
- Tests executed on the emulator;  
- Bugs reported in **Jira**;  
- Overall test status documented in Google Sheets.
